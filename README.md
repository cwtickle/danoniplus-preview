## English

### 📋 Overview
**Dancing☆Onigiri Preview** (`danoniplus-preview`) is an online testing and preview tool designed for [**Dancing☆Onigiri (CW Edition)**](https://github.com/cwtickle/danoniplus), a web-based rhythm game platform.

It allows chart creators and developers to test-play charts, verify compatibility across various versions (from v0.25.x to the latest release), and test custom scripts, themes, and stylesheets directly in the browser.

- **Live Preview Site:** [https://danonicw.skr.jp/](https://danonicw.skr.jp/)

---

### 🚀 Features

1. **Multi-Version Support**
   - Instantly switch and test across dozens of CW Edition versions (v0.25.x ~ latest) to inspect version-specific behaviors and compatibility.
2. **Easy File & Chart Import**
   - **Chart Data:** Directly paste text generated by the editor or upload chart header files.
   - **Audio Upload:** Supports music files up to 64 MB.
   - **Image Assets:** Upload custom backgrounds, masks, and graphic assets.
3. **Advanced Display & Theme Customization**
   - Customizable viewport sizes (Width / Height) and keymodes (`difData`).
   - URL query parameter integration (e.g., `scoreId=2&dos=001`).
   - Upload custom JavaScript and CSS for themes, skins, and modifications.
4. **Automatic Maintenance**
   - Uploaded temporary assets are automatically purged daily at 6:00 AM (JST / GMT+9).

---

### 🎮 How to Use

1. **Visit the Site:** Go to [https://danonicw.skr.jp/](https://danonicw.skr.jp/).
2. **Input Chart & Audio:**
   - Paste your exported chart header text into the **Chart Data** field (or upload the chart file).
   - Upload your music file in the **Music File** section.
3. **Configure Settings (Optional):**
   - Select the target CW Edition version, resolution, keymode, or custom JS/CSS files as needed.
4. **Play / Preview:**
   - Click **"Click Here!!"** or press the **Enter** key to start test-playing.

## 日本語

### 📋 概要
**Dancing☆Onigiri Preview** (`danoniplus-preview`) は、Webリズムゲーム [**Dancing☆Onigiri (CW Edition)**](https://github.com/cwtickle/danoniplus) の譜面制作・動作検証・テストプレイをブラウザ上で行うためのプレビューツールです。

最新版から過去の旧バージョン（v0.25.x 〜 最新バージョン）までの動作比較や、カスタムJavaScript / CSS（スキン・テーマ）の適用検証などを手軽に行うことができます。

- **Webサイト (Live Demo):** [https://danonicw.skr.jp/](https://danonicw.skr.jp/)

---

### 🚀 主な機能

1. **バージョン選択機能**
   - 多岐にわたる Dancing☆Onigiri (CW Edition) の各バージョンをドロップダウンで選択し、特定のバージョンでの挙動を即座に確認できます。
2. **直感的なファイルアップロード / 入力**
   - **譜面データ (Chart Data):** エディター出力テキストの直接貼り付け、またはファイルのアップロードに対応。
   - **楽曲ファイル (Audio File):** 最大 64MB までの音声ファイル（MP3/OGG等）に対応。
   - **画像ファイル (Image Files):** 背景やマスク画像のセットを一括アップロード。
3. **柔軟なカスタム設定**
   - 表示サイズ（幅・高さ）やキーモード (difData) の指定。
   - URLクエリパラメーター経由での設定引き継ぎ (`scoreId`, `dos` 等)。
   - カスタム JS / CSS、スモーク/テーマ用スクリプトのロード。
4. **自動クリーンアップ**
   - アップロードされたテストデータは毎日午前6時（JST / GMT+9）に自動消去されるため、安全かつ軽量に利用可能です。

---

### 🎮 使い方

1. **サイトにアクセス:** [https://danonicw.skr.jp/](https://danonicw.skr.jp/) にアクセスします。
2. **データの準備 & 投入:**
   - 「Chart / 譜面データ」エリアにエディターで出力したデータテキストを貼り付け、またはファイルを読み込みます。
   - 「Music File / 楽曲ファイル」で対応する音声ファイルをアップロードします。
3. **各種オプションの設定:**
   - 検証したい CW Edition のバージョン、画面サイズ、背景画像、カスタムJS/CSSなどを必要に応じて設定します。
4. **テストプレイの開始:**
   - 画面中央の「Click Here!!」または Enter キーを押してプレイを開始します。
